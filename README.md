# Classical Cryptography Toolkit

This ZIP contains the Flutter source files for the Network Security mini-project.

IMPORTANT:
The Android emulator is NOT stored inside a ZIP. The emulator is created separately in Android Studio.

This package includes a SETUP_PROJECT.bat file. Run it after installing Flutter and Android Studio. It will:
1. Create the missing Flutter Android/platform files.
2. Restore the supplied pubspec.yaml.
3. Run flutter pub get.

Then use `flutter run` while an Android emulator is running.
